# 👨‍💼 HR Analytics - Employee Attrition Prediction

A Machine Learning project that predicts whether an employee is likely to leave the organization based on HR data. The project uses data preprocessing, visualization, and a Random Forest Classifier to identify attrition patterns and help organizations make data-driven HR decisions.

## 📌 Project Overview

Employee attrition is a major challenge for organizations as it affects productivity and increases recruitment costs. This project analyzes employee data to predict attrition using machine learning and highlights the factors that contribute most to employee turnover.

## 🚀 Features

- Data preprocessing and cleaning
- Categorical data encoding
- Missing value handling
- Exploratory Data Analysis (EDA)
- Employee attrition visualization
- Random Forest classification model
- Model performance evaluation
- Feature importance analysis
- Attrition probability prediction

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📊 Workflow

1. Load HR employee dataset
2. Clean and preprocess data
3. Encode categorical variables
4. Handle missing values
5. Perform Exploratory Data Analysis (EDA)
6. Split data into training and testing sets
7. Train a Random Forest Classifier
8. Evaluate model performance
9. Visualize feature importance
10. Predict employee attrition

## 📈 Model Evaluation

The model is evaluated using:

- Accuracy Score
- Classification Report
- Confusion Matrix
